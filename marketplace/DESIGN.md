# SystemMarket — интерфейс Liquid Glass

Строгий интерфейс в стиле «жидкого стекла»: глубокая нейтральная основа, полупрозрачные матовые слои с размытием фона, тонкая светлая обводка с бликом по кромке, плавающая панель навигации со скользящей капсулой. Весь интерфейс — один файл `index.html` (разметка, стили, скрипт). Приложение для Android показывает этот же сайт, поэтому обновляется вместе с ним.

## 1. Токены

Все цвета, размеры и время анимаций задаются переменными в `:root`. Тема меняется атрибутами на `<html>`; скрипт в `<head>` ставит их до отрисовки, поэтому экран не мигает.

| Атрибут | Значения | Что меняет |
|---|---|---|
| `data-theme` | `dark` (по умолчанию), `light`, нет атрибута = как в системе | палитра |
| `data-glass` | `rich` (22 px), `soft` (12 px), `off` (без размытия, плотный фон) | сила стекла |
| `data-accent` | `blue` (по умолчанию), `green`, `violet` | акцентный цвет |
| `data-motion` | `full`, `reduced` (все длительности ≈ 0) | анимации |
| `data-text` | `large` | базовый размер 15 → 17 px |

**Цвета** (тёмная / светлая):

| Токен | Назначение | Тёмная | Светлая |
|---|---|---|---|
| `--bg` | основа | `#06080c` | `#e7ebf1` |
| `--text`, `--text-2`, `--text-3` | текст: основной, вторичный, третичный | `#edf1f7` / 66 % / 42 % | `#0b1220` / 62 % / 42 % |
| `--card`, `--card-2`, `--card-press` | полупрозрачные поверхности: обычная, приподнятая, нажатая | белый 3,8 / 6,5 / 10 % | белый 60 / 78 / 95 % |
| `--glass`, `--glass-2` | плавающие стеклянные слои и шторки | `rgba(22,26,35,.56)` | `rgba(250,252,255,.62)` |
| `--line`, `--line-2`, `--line-3` | обводка в 1 px | белый 7,5 / 13 / 20 % | тёмный 7,5 / 12 / 20 % |
| `--hl`, `--rim-1`, `--rim-2` | блик по верхней кромке и градиентная обводка | белый 11 / 30 / 7 % | белый 85 / 95 / 45 % |
| `--accent`, `--accent-f`, `--accent-s` | акцент: текст и значки, заливка кнопок, мягкий фон | `#5b96ff` / `#2f6fed` / 15 % | `#1f5fd6` / `#2563eb` / 10 % |
| `--ok`, `--warn`, `--err` (+ `-s` мягкий фон) | приглушённые статусы | `#4cc38a`, `#e0b25b`, `#f0726b` | `#14805a`, `#9a6205`, `#cc3f37` |

**Скругления:** `--r1` 10, `--r2` 14, `--r3` 18, `--r4` 22, `--r5` 28 px; панель — 26 px, капсула — 20 px, пилюли — 999 px.

**Типографика:** системный шрифт (`system-ui`, SF Pro, Segoe UI, Roboto). Размеры в `rem` от базового 15 px. Заголовок страницы — 2,05 rem / 800 / −0,03 em; заголовок раздела — 1,13 rem / 700; подписи групп — 0,74 rem, заглавные, разрядка 0,08 em. Цены, счётчики, время и проценты — `font-variant-numeric: tabular-nums`.

**Движение:** `--e-out` `cubic-bezier(.22,1,.36,1)`, `--e-spring` `cubic-bezier(.32,.72,0,1)`, `--e-pop` `cubic-bezier(.34,1.45,.64,1)`, `--e-in` для ухода. Длительности: `--t1` 140 мс (нажатие), `--t2` 240 мс (появление, меню), `--t3` 420 мс (шторки, экраны), `--t4` 560 мс (капсула панели). Анимируются только `transform` и `opacity`.

## 2. Стекло

| Класс | Что это |
|---|---|
| `.glass` | тонированный фон `--glass` + `backdrop-filter: blur(--blur) saturate(--sat)` + обводка `--line-2` + внутренний блик `inset 0 1px 0 --hl` + тень |
| `.rim` | градиентная обводка 1 px (`::after` с маской): светлый блик в верхнем левом углу, мягкий отсвет внизу справа |
| `.surface`, `.card`, `.group-card` | полупрозрачная поверхность **без** размытия: для карточек в ленте, чтобы не нагружать слабые телефоны |

Размытие получают только плавающие слои: шапка при прокрутке, нижняя панель, строка поиска, меню, окна подтверждения, уведомления, панель ввода сообщения, шапки шторок. Если браузер не умеет `backdrop-filter`, стекло автоматически становится плотным (`@supports not`), так же как в режиме «Выключен».

## 5. Логика состояний

- **`prefs`** — настройки устройства (`localStorage sm_prefs`): `theme, glass, accent, motion, bigText, notify, sound, vibrate, saver, quality, poll`. `prefs.set()` сохраняет и сразу применяет атрибуты (`applyPrefs`). Тот же разбор повторяет скрипт в `<head>`.
- **`state.page`** — текущая страница; `renderPage()` перерисовывает шапку, панель и `<main id="view">`, запускает въезд экрана.
- **Страницы и шторки.** Страницы рисуются в `#view`; шторки открываются поверх. Возврат из шторки на ту же страницу её не перерисовывает (сохраняется прокрутка), если не взведён `needsReload` (объявление изменено, продано, удалено, опубликовано). `sheetTrail` помнит цепочку шторок: из переписки «Назад» ведёт в объявление, и переписка уезжает вправо.
- **`feed`, `search`** — данные ленты и поиска с номером запроса `req`: устаревший ответ не перерисует экран. Поиск синхронизирует адрес через `history.replaceState`.
- **`ops`** — загрузки: `run (p 0…1)` → `done (href)` | `fail (err, retry)`. Завершённые сохраняются (`sm_ops`, 40 последних), идущие живут в памяти. Публикация объявления и каждое фото, видео, голосовое в переписке создают операцию; «Повторить» отправляет тот же файл в ту же переписку, даже если окно уже закрыто.
- **`net`** — подключение: события `online/offline`, проверка `/api/health` с временем ответа; без связи сверху появляется стеклянная плашка с «Повторить».
- **Непрочитанные** — опрос `/api/chats/unread` с частотой из настроек; новое сообщение: уведомление с «Открыть», звук (Web Audio), вибрация; число в заголовке вкладки браузера.
- **`qhist`** — 10 недавних запросов (`sm_qhist`); **`myCache`** — мои объявления на 30 секунд.

## 6. Уведомления, просмотры и новые возможности

- **Кто написал.** Каждое сообщение создаёт на сервере уведомление получателю: имя, объявление, текст или «Фото / Видео / Голосовое». Несколько сообщений одной переписки сливаются: «Aman: новых сообщений — 3». Открыли переписку — её уведомления прочитаны.
- **Как приходят.** Опрос `/api/chats/unread` (частота из настроек) сообщает число непрочитанных и номер последнего уведомления. Новое показывается всплывающей плашкой «Новое сообщение от Aman: …» с кнопкой «Открыть», звуком и вибрацией (если включены), а при свёрнутой вкладке — уведомлением браузера (в Настройках, на компьютере и в браузере телефона).
- **Просмотры по людям.** Один человек (устройство или аккаунт) — один просмотр, свои не считаются. В объявлении: «N человек посмотрели · сегодня M · K смотрят сейчас · в избранном у L». Продавцу приходят уведомления на 1, 5, 10, 25, 50, 100… просмотрах.
- **Избранное на сервере.** Продавец видит, сколько людей сохранили объявление; сохранившим приходит уведомление о снижении цены (старая цена зачёркнута, на карточке — зелёная стрелка) и о продаже.
- **Слежу за поиском.** Кнопка над результатами сохраняет поиск со всеми фильтрами; о каждом новом подходящем объявлении приходит уведомление. Список — на стартовом экране поиска.
- **Фильтры авто и недвижимости.** Марка, год от–до, коробка, топливо, пробег; тип сделки и комнаты; «Возможен обмен», «Кредит или рассрочка». Всё хранится в адресе поиска.
- **Условия сделки.** В форме: «Торг уместен», «Возможен обмен», «Кредит или рассрочка» — видны тегами в объявлении.
- **Поднять в поиске.** Своё объявление — наверх ленты бесплатно раз в сутки (кнопка в объявлении и в «Моих объявлениях» показывает, через сколько можно).
- **Другие объявления продавца** — лента внизу объявления.
- **График посетителей** (админ-панель): один ряд — без легенды; столбцы до 18 px со скруглённым верхом; подписаны только максимум и сегодня; подсказка на каждом столбце по наведению, касанию и фокусу; таблица по кнопке; цвет столбцов проверен на контраст в обеих темах (`--chart-1`).

## 7. Анимации

| Что | Как |
|---|---|
| Смена экрана | `opacity 0→1`, `translateY 10→0`, 420 мс, `--e-out` |
| Капсула панели | `translateX`, 560 мс, пружина |
| Объявление и переписка | въезд справа `translateX(100 %→0)` 420 мс пружиной; уход 240 мс; назад — текущая уезжает, предыдущая уже на месте |
| Форма | въезд снизу |
| Окно подтверждения, меню, уведомление, фильтры | `scale` + `opacity` (меню — из точки кнопки) |
| Нажатия | кнопки `scale(.97)`, значки `scale(.9)`, вкладки `scale(.84)`, сердечко — «пульс» |
| Переключатель | ползунок `translateX` пружиной, заливка `opacity` |
| Сообщения | новое сообщение всплывает `translateY` + `scale` |
| Загрузка | скелетоны (мерцание), спиннеры, полосы `scaleX` |

При выключенных анимациях (или системной настройке «уменьшить движение» при первом запуске) все длительности становятся ≈ 0, мерцание скелетонов отключается.

## 8. Доступность

Вкладки — `aria-current="page"`; сегменты — `role="radiogroup"`/`radio`; переключатели — `role="switch"` с `aria-checked`; меню — `role="menu"`/`menuitemradio` и управление с клавиатуры; окна — `role="alertdialog"`, `aria-modal`, ловушка фокуса, Esc. Видимый фокус — кольцо акцентного цвета (`:focus-visible`). Контраст текста на заливке кнопок не ниже 4,5 : 1. Поля ввода — не меньше 16 px, чтобы телефон не увеличивал страницу.

## 9. Где что в `index.html`

Стили идут разделами 1–13 (токены → база → стекло → каркас → элементы → карточки → экраны → окна → объявление → форма → переписка → админ-панель → анимации). Скрипт: словари и утилиты → настройки, звук, сеть, загрузки, окна и меню, каркас → данные устройства и API → экраны (главная, поиск, фильтры, сообщения, активность, настройки) → объявление → форма → переписка → админ-панель → навигация → запуск.
