# SystemMarket для Android

Приложение открывает сайт https://sstymmarket.click — всё работает как на сайте
(объявления, подача с фото, переписка с голосовыми, фото и видео, «Написать
администратору», вход через Google, три языка, тёмная тема), а данные приходят
с сервера через интернет. Изменения сайта сразу видны в приложении — APK
обновлять не нужно.

Что добавляет приложение:

- кнопка «Назад» телефона листает страницы сайта;
- фото и видео — из галереи или сразу с камеры;
- микрофон для голосовых (Android спросит разрешение один раз);
- звонок, WhatsApp, Telegram и другие сайты открываются в своих приложениях;
- вход через Google — в браузере (Google не пускает вход внутри приложений),
  затем браузер возвращает в приложение уже вошедшим;
- экран «Нет связи» с кнопкой «Обновить», если пропал интернет или VPN.

## Сборка

APK собирает GitHub Actions (`.github/workflows/android-apk.yml`) при изменении
папки `android/` и кладёт готовый файл в `marketplace/static/systemmarket.apk`.
Установщик сайта выкладывает его по адресу https://sstymmarket.click/systemmarket.apk.

Скрипт `build.sh` использует официальные инструменты Android SDK без Gradle:
aapt2 → javac → d8 → zipalign → apksigner. Чтобы обновления приложения ставились
поверх старой версии, добавьте в секреты репозитория постоянный ключ подписи
(`ANDROID_KEYSTORE_B64` и `ANDROID_KEYSTORE_PASS`); без них каждая сборка
подписывается новым ключом, и перед установкой новой версии старую нужно удалить.
