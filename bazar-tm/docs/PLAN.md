## День 1 — что сделано

- [x] Структура: `app/` (Flutter), `server/` (NestJS), `docs/`, `docker-compose.yml`, `.env.example`.
- [x] Дизайн-система: цвета светлой и тёмной темы, типографика, отступы, радиусы, анимации, компоненты.
- [x] Экраны-каркасы на демо-данных:
  - главная, каталог (поиск, категории, цена, сортировка), магазин, товар (варианты, наличие);
  - корзина по магазинам, оформление заказа (один магазин — один заказ), мои заказы со статусами;
  - чаты и переписка (текст, фото, голосовое, галочки доставки);
  - профиль: язык, тема, вход, «Я торговец» с кодом приглашения;
  - панель торговца: обзор и подписка, товары (добавить/изменить/скрыть/удалить), заказы (смена статуса), профиль магазина.
- [x] Языки ru/tk, выбор при первом запуске; тёмная, светлая и «Авто» тема.
- [x] Тесты: корзина и заказы (в том числе «один магазин в заказе», переходы статусов), права торговца на товары,
  телефон +993, тексты ru/tk совпадают, все экраны открываются без ошибок на узком и широком экране в обоих языках и темах.
- [x] Сервер: каркас NestJS, `/api/v1/health`, защита заголовков (helmet), CORS, проверка входных данных, тесты.
- [x] Автосборка на GitHub: проверки + APK.

## День 2 — что сделано

Решения по вопросам дня 2 (владелец ответил «Да», выбраны простые варианты, их можно поменять):
- регистрация без SMS;
- забытый пароль восстанавливает владелец: он выдаёт временный пароль, и приложение сразу просит придумать новый;
- домен и сервер выберем позже: коду они не нужны.

- [x] PostgreSQL: таблицы `users`, `shops`, `invites`, `sessions`, `audit_log`. Миграции запускаются сами при старте сервера.
- [x] Регистрация и вход по телефону и паролю. Пароли хранятся как Argon2id. После 5 неверных паролей пауза 15 минут.
- [x] Вход через Google: сервер сам проверяет токен Google. Если Google выключен или недоступен, приложение предлагает вход по телефону.
- [x] Токены: доступ на 15 минут, обновление на 30 дней. Старый токен обновления, использованный повторно, закрывает сессию. Есть «Выйти» и «Выйти на всех устройствах».
- [x] Роли owner / seller / buyer. Права проверяются на каждом запросе. Торговец видит только свой магазин.
- [x] Приглашения торговцев: владелец создаёт одноразовый код на 7 дней. Покупатель вводит его в профиле и становится торговцем, магазин открывается с бесплатным месяцем.
- [x] Владелец (пока через API, экран владельца будет на день 7): поиск пользователей, блокировка, сброс пароля, список и отзыв приглашений. Все действия записываются в журнал.
- [x] Владелец создаётся командой на сервере `npm run owner:create`: пароль не виден на экране и не остаётся в истории.
- [x] Приложение:
  - настоящие экраны входа, регистрации и смены пароля;
  - профиль с ролью, магазином и кнопками выхода;
  - ввод кода торговца;
  - понятные ошибки на ru/tk;
  - вход сохраняется на телефоне в защищённом хранилище и работает без интернета.
- [x] Тесты: 111 на сервере (на настоящем PostgreSQL), 66 в приложении. Чеклист безопасности: [SECURITY.md](SECURITY.md).

## День 3 — предложение (после вашего «да»)

1. Товары на сервере: создать, изменить, скрыть, удалить; цена в TMT, остаток, категория, варианты.
2. Профиль магазина на сервере: название, логотип, описание, адрес и рынок, часы работы.
3. Фото товаров:
   - телефон сжимает фото до 1280 px;
   - сервер проверяет, что это действительно картинка, ограничивает размер и даёт файлу новое имя;
   - ссылки на фото временные.
4. Категории с названиями на русском и туркменском.
5. Панель торговца в приложении работает с сервером вместо демо-данных.
6. Тесты: торговец не может изменить чужой товар, лимиты загрузки.

## Вопросы владельцу перед днём 3

1. **Где поставить сервер, чтобы вы проверили вход на своём телефоне?** Без него приложение показывает «сервер не подключён».
   - а) Новый сервер на 2 ГБ памяти (около 5–10 $ в месяц). Советую этот вариант: на нём будет работать весь Bazar TM. Я подготовлю команду установки, как для SystemMarket.
   - б) Пока на текущем сервере sstymmarket.click. Бесплатно, но там всего 512 МБ памяти, и это может замедлить SystemMarket.
2. **Где хранить фото товаров?**
   - а) На диске нашего сервера. Просто, не зависит от зарубежных сервисов.
   - б) В облачном хранилище S3. Удобнее при росте, но может быть недоступно из Туркменистана.
3. **Лимиты товаров по тарифам** (Старт — 50, Бизнес — 300 товаров):
   - а) Включить сразу.
   - б) Пока только считать, а включить в день 7 вместе с подписками.
