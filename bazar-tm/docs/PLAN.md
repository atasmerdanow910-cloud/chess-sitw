# План по дням

Работаем по одному дню. Следующий день начинается только после подтверждения владельца.

| День | Что делаем | Статус |
|---|---|---|
| 1 | Основа и дизайн: структура, дизайн-система, экраны-каркасы, ru/tk, темы | ✅ готово, ждёт проверки владельцем |
| 2 | Безопасность и вход: база данных, регистрация/вход, роли, JWT, лимиты, приглашения торговцев | ⏳ ждёт подтверждения |
| 3 | Магазины и товары: панель торговца на сервере, фото, категории, остатки, хранилище файлов | — |
| 4 | Каталог покупателя: главная, поиск, фильтры, магазин, товар, избранное — с сервера | — |
| 5 | Заказы: корзина, оформление, статусы, уведомления торговцу | — |
| 6 | Чат: реальное время, фото/видео/голосовые, статусы, push | — |
| 7 | Панель владельца и подписки | — |
| 8 | Полная проверка безопасности, нагрузочный тест | — |
| 9 | Проверка из Туркменистана, релизная подпись APK, запуск | — |

## День 1 — что сделано

- [x] Структура: `app/` (Flutter), `server/` (NestJS), `docs/`, `docker-compose.yml`, `.env.example`.
- [x] Дизайн-система: цвета светлой и тёмной темы, типографика, отступы, радиусы, анимации, компоненты.
- [x] Экраны-каркасы на демо-данных:
  - главная, каталог (поиск, категории, цена, сортировка), магазин, товар (варианты, наличие);
  - корзина по магазинам, оформление заказа (один магазин — один заказ), мои заказы со статусами;
  - чаты и переписка (текст, фото, голосовое, галочки доставки);
  - профиль: язык, тема, вход, «Я торговец» с кодом приглашения;
  - панель торговца: обзор и подписка, товары (добавить/изменить/скрыть/удалить), заказы (смена статуса), профиль магазина.
- [x] Языки ru/tk, выбор при первом запуске; тёмная, светлая и «Авто» тема.
- [x] Тесты: корзина и заказы (в том числе «один магазин в заказе», переходы статусов), права торговца на товары,
  телефон +993, тексты ru/tk совпадают, все экраны открываются без ошибок на узком и широком экране в обоих языках и темах.
- [x] Сервер: каркас NestJS, `/api/v1/health`, защита заголовков (helmet), CORS, проверка входных данных, тесты.
- [x] Автосборка на GitHub: проверки + APK.

## День 2 — предложение (после вашего «да»)

1. PostgreSQL в docker-compose, миграции: `users`, `shops`, `invites`, `sessions`, `audit_log`.
2. Регистрация и вход по телефону и паролю (пароли — argon2), блокировка после неудачных попыток.
3. Вход через Google (проверка токена на сервере), и приложение не «умирает», если Google недоступен.
4. JWT: короткий access и refresh с ротацией, выход со всех устройств.
5. Роли `owner` / `seller` / `buyer`, проверка прав на каждом запросе, тесты «чужие данные недоступны».
6. Приглашения торговцев: владелец создаёт код, торговец вводит его в приложении.
7. Ограничение частоты запросов (вход, регистрация).
8. Приложение: настоящие экраны входа и регистрации, токены в защищённом хранилище телефона.

## Вопросы владельцу перед днём 2

1. **Подтверждение номера по SMS при регистрации?**
   - а) Пока без SMS: номер проверяет торговец, когда звонит по заказу. Быстро и бесплатно.
   - б) SMS-код через местного провайдера. Нужен договор, и каждое SMS платное.
2. **Как восстанавливать забытый пароль?**
   - а) Через поддержку: человек пишет владельцу, владелец сбрасывает пароль в своей панели.
   - б) По SMS (только если выбран пункт 1б).
3. **Адрес сервера (API):**
   - а) Поддомен текущего сайта, например `api.sstymmarket.click`. Быстрее всего.
   - б) Новый домен под Bazar TM.
4. **Открывается ли ваш текущий сервер в Туркменистане без VPN?** Проверьте на мобильном интернете
   и на Türkmentelekom. От этого зависит, где держать сервер Bazar TM (ТЗ, раздел 3).
