{{ glogo() }}Вход через Google

Посетители регистрируются и входят через аккаунт Google.

Google разрешает вход только на сайтах с доменом и HTTPS. Сначала подключите домен через Cloudflare (вкладка «Защита») и укажите адрес сайта в «Настройках».
Как получить Client ID и Secret
  1. Откройте console.cloud.google.com и создайте проект.
  2. APIs & Services → OAuth consent screen: тип External, укажите название и email, сохраните. Затем нажмите Publish app, чтобы входить мог любой пользователь.
  3. Credentials → Create credentials → OAuth client ID, тип Web application.
  4. В Authorized redirect URIs вставьте адрес из поля «Redirect URI» выше.
  5. Скопируйте Client ID и Client Secret сюда и сохраните.

{{ ic("cloud") }}Cloudflare — защита от DDoS

Cloudflare принимает весь трафик на себя, отсеивает атаки и ботов и бесплатно даёт HTTPS. Сайт видит настоящие IP посетителей через заголовки Cloudflare.

Как подключить Cloudflare
  1. Купите домен (подойдёт любой недорогой) и добавьте его в dash.cloudflare.com (тариф Free).
  2. У регистратора домена замените NS-серверы на те, что выдаст Cloudflare.
  3. DNS: запись A, имя @, значение — IP сервера, облако оранжевое (Proxied).
  4. SSL/TLS: режим Flexible, включите Always Use HTTPS.
  5. Security → Bots: включите Bot Fight Mode. Во время атаки — Under Attack Mode.
  6. Откройте админку по домену и включите переключатель выше.
  7. Для полной защиты закройте сервер фаерволом: bash deploy/install.sh --cloudflare-firewall
